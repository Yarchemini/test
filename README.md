# Виджет банковских операций

Проект для удобной работы с историей банковских операций клиента. 

## Что умеет проект:
* Маскировать номера карт и счетов (модуль `masks`).
* Менять формат даты на читаемый (модуль `widget`).
* Фильтровать операции по их статусу и сортировать по дате (модуль `processing`).
* Эффективно обрабатывать большие объемы транзакций через генераторы (модуль `generators`).
* Автоматически логировать выполнение функций и отлавливать ошибки с помощью декоратора `@log` (модуль `decorators`).
* Читать банковские операции из формата JSON и автоматически конвертировать валюты (USD/EUR) в рубли через внешнее API (модули `utils` и `external_api`).




## Как установить:
1. Скачать проект.
2. Установить зависимости через Poetry:
   ```bash
   poetry install
   ```

## Примеры использования функций из `processing.py`:

```python
from src.processing import filter_by_state, sort_by_date

# Фильтрация по статусу (по умолчанию EXECUTED)
print(filter_by_state(test_data))

# Фильтрация отмененных операций
print(filter_by_state(test_data, "CANCELED"))

# Сортировка от самых свежих к старым
print(sort_by_date(test_data))
```

## Тестирование
В проекте реализованы автоматические тесты с использованием библиотеки `pytest`.
Для запуска тестов и генерации HTML-отчета о покрытии кода (coverage) выполните команды:
```powershell
\$env:PYTHONPATH="."
poetry run pytest --cov=src --cov-report=html
```
